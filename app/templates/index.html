About the System

This machine learning application predicts potential Air Pressure System (APS) failures in Scania trucks.

The system uses a Random Forest classification model trained on the Scania APS Failure dataset.

  • Model: Random Forest Classifier
  • Purpose: Predict potential APS failures before they occur
  • Dataset Records: {{ total_records }}
  • Features: 163 machine sensor features
  • Evaluation: Accuracy, Precision, Recall, F1 Score and ROC-AUC
